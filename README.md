# SQL Data Analysis – E-Commerce Database

##  Project Overview

This project focuses on analyzing an e-commerce database using SQL and MySQL Workbench.

A sample e-commerce database was created with customers, products, and orders. SQL queries were then used to retrieve, filter, organize, and analyze the data.

##  Objective

The objective of this project is to gain practical experience in:

- Retrieving data using SQL
- Filtering and sorting data
- Performing data analysis using aggregate functions
- Grouping data
- Combining multiple tables using JOINs
- Using subqueries
- Creating SQL views
- Creating indexes for query optimization

##  Tools Used

- MySQL
- MySQL Workbench
- SQL
- GitHub

##  Database Structure

The database `ecommerce_analysis` contains three tables:

### 1. Customers

Contains:
- Customer ID
- Customer Name
- City

### 2. Products

Contains:
- Product ID
- Product Name
- Category
- Price

### 3. Orders

Contains:
- Order ID
- Customer ID
- Product ID
- Quantity
- Order Date

##  SQL Concepts Used

The following SQL concepts were implemented:

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()
- INNER JOIN
- LEFT JOIN
- RIGHT JOIN
- Subqueries
- SQL Views
- Indexes

##  Analysis Performed

The project includes analysis such as:

- Retrieving customer information
- Filtering customers by city
- Sorting products by price
- Counting products by category
- Calculating total revenue
- Calculating average product price
- Calculating category-wise revenue
- Combining order and product information using INNER JOIN
- Displaying customers and their orders using LEFT JOIN
- Displaying all products using RIGHT JOIN
- Finding products priced above the average price using a subquery
- Creating a revenue analysis view
- Creating an index on the customer ID column
